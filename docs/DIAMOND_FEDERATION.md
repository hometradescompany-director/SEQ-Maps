# SEQ Maps <-> Diamond boundary v0.1

SEQ Maps is the discovery and normalization environment. Diamond is the provenance and authority-aware security boundary.

SEQ Maps may emit opaque source, observation, entity and evidence references. Diamond may consume those references for validation or policy evaluation.

Neither system should duplicate the other's canonical registry or share mutable storage by default.

A valid SEQ Maps record never grants Diamond execution authority, and a Diamond decision never changes geographic source data. Consequential actions remain behind explicit authorization gates.
